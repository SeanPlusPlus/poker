# Poker Coach

Personal poker strategy assistant for live No-Limit Texas Hold'em cash games and tournaments.

## What This Is

A Claude Code workspace for real-time poker coaching: preflop ranges, postflop strategy, bet sizing, ICM considerations, reads/tells, and session review.

## Game Context

- **Format:** Live NL Hold'em — casual home games with strong players
- **Structure:** Multi-table tournaments with re-buy periods, consolidating to one table
- **Environment:** Social (beers, food) but competitive

## Usage

Open a Claude Code session in this directory for:
- **Pre-session prep** — strategy reminders, opponent tendencies, mental game
- **Hand analysis** — post-session review of key hands
- **Concept deep-dives** — ranges, pot odds, implied odds, position play, ICM
- **Situational strategy** — re-buy period play, bubble dynamics, short-handed adjustments
